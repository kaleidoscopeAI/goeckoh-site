Get Started with Goeckoh

Choose your platform and start your voice therapy journey today. All downloads are free and open source.

💻 Desktop

Desktop Platforms

🐧

Linux

Debian, Ubuntu, and compatible distributions

📦 DEB Package Easy Install 📁 Source Tarball Advanced Users

Installation Instructions

  1. Download the .deb package
  2. Open terminal in download directory
  3. Run:
    sudo dpkg -i goeckoh-system_1.0.0_all.deb
  4. Launch from applications menu or terminal:
    goeckoh

System Requirements

  • Ubuntu 20.04+ or Debian 11+
  • Python 3.8 or higher
  • 4GB RAM minimum (8GB recommended)
  • Working microphone and speakers/headphones
  • 2GB free disk space
🪟

Windows

Windows 10 and Windows 11

📦 Installer (EXE) Recommended 📁 Portable ZIP No Installation

Installation Instructions

  1. Download the installer (goeckoh-installer.exe)
  2. Run the installer and follow the setup wizard
  3. Choose installation directory (default: C:\Program Files\Goeckoh)
  4. Launch from Start Menu or desktop shortcut

System Requirements

  • Windows 10 (build 1809+) or Windows 11
  • Python 3.8 or higher (included in installer)
  • 4GB RAM minimum (8GB recommended)
  • Working microphone and audio output
  • 2GB free disk space
🍎

macOS

macOS 11 (Big Sur) and later

📦 DMG Installer Easy Install 📁 App Bundle Advanced

Installation Instructions

  1. Download the DMG file (goeckoh-system-1.0.0-macos.dmg)
  2. Open the DMG file
  3. Drag Goeckoh.app to your Applications folder
  4. Launch from Applications or Spotlight
  5. Grant microphone permissions when prompted

System Requirements

  • macOS 11 (Big Sur) or later
  • Apple Silicon (M1/M2) or Intel processor
  • 4GB RAM minimum (8GB recommended)
  • Working microphone and audio output
  • 2GB free disk space
📱 Mobile

Mobile Platforms

📱

Android

Android 8.0 (Oreo) and later

📦 APK Package Direct Install

Installation Instructions

  1. Download the APK file (goeckoh-1.0.0.apk)
  2. Enable "Install from Unknown Sources" in Settings → Security
  3. Open the APK file and tap Install
  4. Grant microphone permissions when prompted
  5. Launch Goeckoh from your app drawer

System Requirements

  • Android 8.0 (Oreo) or later
  • 2GB RAM minimum (4GB recommended)
  • Working microphone
  • 500MB free storage
📱

iOS

iOS 14 and later, iPadOS 14+

🧪 TestFlight Beta Testing

Installation Instructions

  1. Install TestFlight from the App Store
  2. Click the Goeckoh TestFlight invitation link
  3. Accept the invitation and install Goeckoh
  4. Grant microphone permissions when prompted
  5. Launch from your home screen

System Requirements

  • iOS 14 or later, iPadOS 14+
  • iPhone 7 or later, iPad 5th gen+
  • Working microphone
  • 500MB free storage

🚀 Quick Start Guide

1️⃣ First Launch

When you first launch Goeckoh, you'll be guided through a quick setup process:

  • Select your audio input/output devices
  • Record a 5+ second voice sample for cloning
  • Choose your preferred mode (GUI, Universe, or Child)
  • Configure sensitivity settings if needed

2️⃣ Using Goeckoh

Once set up, using Goeckoh is simple:

  • Speak naturally into your microphone
  • Goeckoh will process and correct your speech
  • Hear the corrected version in your own voice
  • Watch the visual feedback in real-time
