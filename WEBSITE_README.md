# Goeckoh Website

This directory contains the marketing website for Goeckoh Neural Voice System.

## Structure

- **home.html** - Main landing page with overview
- **science.html** - Comprehensive scientific explanations and technology details
- **features.html** - Detailed feature breakdown and specifications
- **about.html** - Mission, values, and story
- **download.html** - Download instructions for all platforms
- **shared-styles.css** - Common styles and design system
- **logo.svg** - Goeckoh logo (flower-based design with pastel gradients)

## Design System

### Colors
- **Primary**: Light pastel palette
  - Lavender: `#E6E6FA`
  - Mint: `#C8F4DE`
  - Peach: `#FFD6BA`
  - Blue: `#C4E4FF`
  - Pink: `#FFD9EC`
  - Rose: `#FFC9D9`
  - Sage: `#D4E7C5`
  - Yellow: `#FFF8DC`

### Typography
- **Headings**: Playfair Display (elegant serif)
- **Body**: Quicksand (soft, rounded sans-serif)
- **Monospace**: Inter

### Features
- Fully responsive design
- Smooth animations and transitions
- Accessibility-focused
- Cross-browser compatible
- Fast loading times

## Development

To run the website locally:

```bash
npm install
npm run dev
```

The site will be available at `http://localhost:5173`

## Deployment

The website is static HTML/CSS and can be deployed to any web hosting service:
- GitHub Pages
- Netlify
- Vercel
- AWS S3
- Or any static hosting provider

## Navigation

All pages include a consistent navigation bar with links to:
- Home
- Science
- Features
- About
- Download

- High contrast text
- Keyboard navigation support
- Screen reader friendly
